
# iFactory Operating System (iFactory OS)

iFactory OS is a CPU-inspired operating system for multi-stage customized production. It integrates granularity-based synchronization mechanisms to coordinate production demands and manufacturing resources under pervasive uncertainties.

## Demonstration

This repository provides a demonstration video of iFactory OS, showcasing its production management, execution monitoring, and uncertainty handling capabilities through a customized figurine manufacturing case.

## Download

The demonstration video and Windows installation package are available in the [Releases](https://github.com/anmiann/iFactory-Operating-System/releases) section.

## Research

This system was developed to implement and validate the CPU-inspired Granularity-based Synchronization (CPUGS) framework for multi-stage customized production.
